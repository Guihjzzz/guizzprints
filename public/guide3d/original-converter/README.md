# Conversor original do Guizzprints

Esta pasta preserva os recursos estáticos do conversor original utilizado pelo Guia 3D. A página `bridge.html` apenas automatiza a importação e exportação no navegador; os bundles e o algoritmo do conversor permanecem os originais.

Ela é publicada como um projeto estático separado para manter o conversor no mesmo HTTPS do navegador, sem usar `localhost` nem solicitar acesso a outro aplicativo.
